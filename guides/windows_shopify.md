# Setting Up Shopify Dev Environment on Windows 11

This guide purports to explain how to set up a development environment for Shopify
developers on the Windows platform. 

## Overview

Per Shopify's development docs, the Shopify CLI tool "helps you generate and work
with shopify apps, themes, and custom storefronts. You can also use it to automate
many common development tasks."

Requirements: 
- Node.js
- Node package manager
- Git
